# AX-9: Broken Relay

Official static website for **AX-9: Broken Relay**, a tactical decision-making game for iPhone and iPad.

The site uses plain HTML and CSS. It has no cookies, analytics, external fonts, embedded videos or build step.

## GitHub Pages

Publish from the `main` branch and repository root. English is served from `/`; German is available at `/de/`.

## YouTube link

The YouTube buttons currently show “Coming soon” and are intentionally not clickable. Once the channel exists, replace the disabled `span` elements in both HTML files with links to the channel.
